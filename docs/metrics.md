# 指标口径

所有比例都先按赛事（底层接口也兼容日期）、分路等条件确定完整小局窗口，再聚合。接口返回 `filters` 和 `sample_size`，网页会显示样本量。

- 选取率 = 该英雄被选小局数 / 窗口内完整小局数。
- 禁用率 = 该英雄被禁小局数 / 窗口内完整小局数。
- BP 率 =（被选小局数 + 被禁小局数）/ 窗口内完整小局数。
- 胜率 = 该英雄获胜小局数 / 该英雄被选小局数。
- KDA =（总击杀 + 总助攻）/ `max(总死亡, 1)`。
- Pick 顺位 = 按全局 Pick 动作计数的第 1 至第 10 个选择，不是 BP 总动作序号。
- 己方 Pick 顺位 = 在同一小局、同一阵营内按 Pick 动作排序后的第 1 至第 5 个选择。
- 对位 = 同一小局、相反阵营、相同 `role_name` 的英雄。
- 搭档 = 同一小局、同一阵营的另一个英雄。
- 2/3 英雄组合 = 同一小局同一阵营共同上场的无序英雄集合；组合出场率 = 共同出场阵容数 /（完整小局数 × 2 个阵营）。
  - 未指定英雄时分别生成双英雄和三英雄榜，可按共同出场次数或胜率排序；榜单默认至少 2 局样本。
  - 指定单个英雄时返回所有包含该英雄且至少共同出场 1 局的双英雄、三英雄组合。
- 单件装备使用率 = 对局结束时装备栏包含该装备的英雄出场局数 / 该英雄总出场局数。它描述结束时持有情况，不代表购买顺序。
- 铭文页 = 同一小局同一选手的全部铭文名称与数量组成的完整无序集合，例如 `10红月 · 10狩猎 · 10鹰眼`。铭文页使用率 = 使用该完整组合的英雄出场局数 / 该英雄总出场局数；30 枚五级铭文显示为 150 级。

KPL 版本、赛制、队伍和选手会随时间变化，因此跨版本数据不应只看总胜率。建议始终展示时间范围和最小样本量；后续可以加入游戏版本维度和置信区间。
