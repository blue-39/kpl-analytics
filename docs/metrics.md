# 指标口径

所有比例都先按日期、分路等条件确定完整小局窗口，再聚合。接口返回 `filters` 和 `sample_size`，网页会显示样本量。

- 选取率 = 该英雄被选小局数 / 窗口内完整小局数。
- 禁用率 = 该英雄被禁小局数 / 窗口内完整小局数。
- BP 率 =（被选小局数 + 被禁小局数）/ 窗口内完整小局数。
- 胜率 = 该英雄获胜小局数 / 该英雄被选小局数。
- KDA =（总击杀 + 总助攻）/ `max(总死亡, 1)`。
- Pick 顺位 = 按全局 Pick 动作计数的第 1 至第 10 个选择，不是 BP 总动作序号。
- 对位 = 同一小局、相反阵营、相同 `role_name` 的英雄。
- 搭档 = 同一小局、同一阵营的另一个英雄。
- 双英雄组合 = 同一小局同一阵营共同上场的无序英雄对。
- 出装组合 = 对局结束时按装备槽排序后拼成的完整组合。
- 铭文使用率 = 带有该铭文的英雄出场局数 / 该英雄总出场局数。

KPL 版本、赛制、队伍和选手会随时间变化，因此跨版本数据不应只看总胜率。建议始终展示时间范围和最小样本量；后续可以加入游戏版本维度和置信区间。
